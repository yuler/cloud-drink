# 云喝酒 MVP 设计

日期：2026-08-16
状态：已确认

## 产品定位

让异地好友通过手机浏览器进入同一个"虚拟酒桌"，用酒桌游戏互动，弥补无法线下聚餐喝酒的场景。核心仪式感是"输家干杯"的 3D 动画与音效反馈。

## 产品形态（已确定）

- H5 网页（手机浏览器打开即用，分享链接进房）
- 酒桌游戏互动，不含实时语音/视频
- 轻量 3D 预制角色（three.js）
- 2-6 人桌
- 游戏池：大话骰 + 真心话大冒险

## 玩家体验流程

```
打开页面 → 输入昵称 + 选角色 → 创建房间（得 4 位房号 + 分享链接）
好友点链接 → 输入昵称 + 选角色 → 进房
房主选游戏并点"开始"（2-6 人均可开，不强制满员）
房主在局间可"再来一局"或"换游戏"
游戏进行 → 输家自动触发"干杯"动画 → 再来一局 或 换游戏
```

- 无账号系统，昵称即身份
- 无持久化，房间生命周期即会话

## 架构

- 后端：Node.js + Express（托管静态页面）+ Socket.IO（房间与游戏状态同步）
- 前端：three.js 渲染 3D 圆桌、角色、骰子；UI 层用普通 DOM，不引重型框架
- 游戏逻辑放服务端（权威服务器）：客户端只发指令、收状态，防止玩家改数据
- 手机浏览器优先，桌面可用

## 房间与状态机

- 房间：`roomId`（4 位码）、`players`（≤6）、`owner`、`game`、`round`
- 开局由房主手动开始，不强制满员
- 状态机：`lobby → game → roundResult（干杯）→ game → ...`

## 游戏一：大话骰（简化规则）

- 每人 5 颗骰子，服务端掷，玩家只见自己的
- 轮流叫数（如"3 个 5"），下家加叫或"开"
- 服务端裁决，输家干杯
- 操作面板：叫数数值选择器 + 开牌按钮

## 游戏二：真心话大冒险

- 骰子随机选"倒霉蛋" → 选真心话/大冒险 → 内置题库出题展示给全桌
- 完成后该玩家干杯

## 干杯环节（核心仪式感）

- 输家角色自动动画：举杯 → 一饮而尽 → 空杯翻转 + 碰杯/咕咚音效
- 全桌同步可见；其他人可点"干杯"送出碰杯助兴特效
- 醉意值：干一次 +1，阈值触发脸红、身体摇晃（材质变色 + 轻微旋转）

## 3D 表现（three.js）

- 圆桌 + 每座一位角色 + 座前骰盅
- 6 套预置低模角色（可选颜色），干杯/Idle 动画
- 掷骰翻滚动画、骰点展示

## 边界与错误处理

- 断线：标记离线，30s 内重连恢复；超时踢出
- 房主退出：转移房主；人数 <2 游戏暂停
- 满房拒入、房间不存在提示

## 非目标（YAGNI）

不做账号系统、不做实时语音/视频、不做捏脸商城、不做陌生人大厅、不做 App 打包、不做数据持久化。
